# Apps Web 2026

**Alumno:** Emir2007

## Descripción

Este repositorio contiene las prácticas de la asignatura de Aplicaciones Web correspondientes al periodo septiembre-diciembre 2026.

La práctica 01 corresponde a la configuración del entorno de desarrollo web y contiene un proyecto básico realizado con HTML, CSS y JavaScript.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git
- GitHub
- Node.js
- npm
- Live Server

## Práctica 01

La práctica incluye:

- Configuración de Git y GitHub.
- Creación de un proyecto HTML.
- Uso de CSS para modificar la presentación.
- Uso de JavaScript para agregar interacción.
- Prueba mediante Live Server.
- Uso de DevTools.
- Control de versiones mediante Git.
- Publicación del proyecto en GitHub.
